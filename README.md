# Remote Via Jobs

Live Platform: https://remoteviajobs.work

A modern, fast, and responsive web platform designed to streamline remote job discovery globally. Built with high performance, clean component architecture, and intuitive search filtering.

---

## 🚀 Overview

Remote Via Jobs delivers an intuitive interface for discovering and filtering verified remote career opportunities. The platform prioritizes fast load times, accessible design, and responsive layouts across all device sizes.

## 🛠 Tech Stack

- **Frontend:** React, Next.js
- **Styling:** Tailwind CSS, Responsive Design
- **Backend & Database:** Node.js, Supabase, REST APIs
- **Deployment & Hosting:** Vercel
- **Version Control:** Git, GitHub

## ✨ Key Features

- **Dynamic Job Filtering:** Real-time filtering and search mechanisms for fast role discovery.
- **Responsive Interface:** Tailored for mobile, tablet, and desktop viewports with seamless navigation.
- **Optimized Performance:** Efficient client-side state handling and component-level code splitting.
- **REST API Integration:** Clean data retrieval and structured content rendering.

## 💻 Local Setup & Development

1. Clone the repository:
   
bash
git clone https://github.com/Magnus-Crown/Remote-via-jobs.git


2. Install dependencies:
   
bash
npm install


3. Run the development server:
   
bash
npm run dev


4. Open [http://localhost:3000](http://localhost:3000) in your browser.
